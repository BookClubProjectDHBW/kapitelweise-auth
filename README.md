# Kapitelweise – Anmeldung

Dieser Service kümmert sich um Registrierung und Login.

- Neue Nutzer können sich mit Benutzername und Passwort registrieren.
- Beim Login bekommt man ein Token. Mit diesem Token weisen sich die Nutzer bei allen anderen Teilen von Kapitelweise aus, ohne sich dort erneut anmelden zu müssen.
- Nach einer Registrierung gibt der Service dem GraphQL-Service Bescheid, damit der neue Nutzer direkt eingeladen werden kann.
